🧬 The Story Behind Gamma Linux

Gamma Linux did not begin as a plan to build another Linux distribution.

It began with a simple observation: a lightweight desktop could make old hardware feel alive again.

1

🌱 It Started With Bodhi Linux

The journey began while using Bodhi Linux.

What immediately stood out was Moksha — lightweight, responsive and surprisingly fast even on modest hardware.

2

⚡ Then I Saw How Light It Could Be

Moksha was using roughly 330 MB of RAM while still feeling extremely responsive.

It did not feel like a system struggling to survive. It simply flew.

3

🤔 One Question Changed Everything

A simple question appeared:

"What if I pushed this idea even further?"

What if an operating system could be designed from the beginning around old hardware, limited memory and efficiency?

4

🛡️ WardenOS

The experiment became more serious and eventually became WardenOS.

It was no longer just about trying to make something lightweight. It became an attempt to build a system around a simple philosophy: old hardware still deserves a useful life.

5

🟣 Gamma Linux

WardenOS evolved into what would become Gamma Linux.

The project grew beyond a lightweight desktop experiment into a complete distribution with its own editions, build system, packages, ISO releases and development ecosystem.

6

🚀 From Experiment to 2.7 Warden

What started with curiosity eventually reached Gamma Linux 2.7 — Warden.

The project now focuses on lightweight computing, old hardware, minimalism, performance and giving users control over what they install.

From one lightweight desktop...

No PC deserves to die.

💻 System Requirements

Gamma is designed to run on old hardware, but "minimum" and "recommended" are not the same thing.

Legacy-32

CPU: 32-bit x86
RAM: 512 MB minimum
Storage: 8 GB+
Architecture: i386
Lite-Ghost

CPU: 64-bit x86
RAM: 1 GB minimum
Storage: 10 GB+
Architecture: amd64
Pro-MaxMini

CPU: 64-bit x86
RAM: 2 GB minimum
Storage: 15 GB+
Architecture: amd64
Reality check: These are practical targets, not promises of perfect performance on every machine. RAM usage, graphics hardware, storage speed and desktop workload can significantly affect the experience.

🛠️ How to Install

⚠️ Windows Fast Startup — Read This First

If Windows is installed on the same computer and you plan to dual-boot, disable Windows Fast Startup before installing Gamma Linux.

Windows Fast Startup uses hibernation-related mechanisms instead of performing a completely fresh shutdown. Leaving it enabled can cause problems when Linux accesses Windows partitions.

Open Command Prompt as Administrator in Windows and run: 

powercfg /h off

This disables hibernation and therefore disables Fast Startup. After running the command, perform a complete Windows shutdown before booting the Gamma Linux USB.

🥀 A Lesson From My Own Installation

I personally forgot to disable Windows Fast Startup before installing Bodhi Linux.

The result was a damaged Windows boot environment: the BCD / boot configuration was affected and Windows required recovery work afterward.

This is why Gamma Linux puts this warning directly in the installation guide.

Don't skip this step if Windows is important to you.

1

Prepare Windows

If dual-booting, boot into Windows first. Open an Administrator Command Prompt and run: 

powercfg /h off

Then completely shut down Windows.

2

Create the USB

Write the Gamma Linux ISO to a USB drive using a tool such as Rufus or Ventoy.

For older systems, verify whether the machine boots through Legacy BIOS or UEFI before choosing the appropriate configuration.

3

Boot Gamma Linux

Restart the computer and open the firmware boot menu. Common keys include:

F12 · F11 · Esc · F8 · F9

Select the Gamma Linux USB and start the live environment.

4

Test Before Installing

Use the live environment first. Check your keyboard, display, storage, network and general hardware compatibility.

If everything works correctly, continue to installation.

5

Launch Calamares

Open Install Gamma Linux from the live desktop. The graphical Calamares installer will guide you through:

  • Language and region
  • Keyboard layout
  • Disk configuration
  • User creation
  • Bootloader configuration
  • Final installation
6

Reboot

When installation finishes, reboot the computer and remove the USB drive when requested.

Your installed Gamma Linux system should then boot normally.

Recommended: Always test Gamma Linux in Live Mode before installing it. Your hardware may behave differently from another machine.
