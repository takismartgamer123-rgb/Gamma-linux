Bienvenue dans Gamma Linux

Gamma Linux est un projet de distribution libre et open source dont l’objectif est de donner une nouvelle utilité aux anciens ordinateurs.

À lire avant de commencer : Gamma est en développement actif. Le bureau, les paquets, l’installateur, la compatibilité matérielle et les exigences peuvent changer d’une image ISO à l’autre. Les notes de version de l’ISO utilisée restent la référence finale.

Cette documentation présente le parcours général. Si une instruction diffère des notes de version ou des scripts de la branche utilisée, suivez les informations propres à cette version.

Choisir la bonne édition

Commencez par vérifier l’architecture du processeur, puis tenez compte de la mémoire et du stockage. Les valeurs ci-dessous sont des objectifs pratiques publiés sur le site du projet, pas des garanties de performances.

ÉditionArchitectureRAM cibleStockage cibleUsage prévu
Legacy-32x86 32 bits (i386)512 Mo+8 Go+Anciens ordinateurs 32 bits
Lite-Ghostx86 64 bits (amd64)1 Go+10 Go+Systèmes 64 bits modestes
Pro-MaxMinix86 64 bits (amd64)2 Go+15 Go+Machines plus puissantes
Compatibilité : Un processeur 32 bits ne peut pas exécuter une image amd64. Un processeur 64 bits peut prendre en charge plusieurs modes, mais le firmware et les fichiers de démarrage doivent aussi correspondre. Vérifiez le processeur et le firmware avant le téléchargement.

Les noms et caractéristiques des éditions peuvent évoluer. Consultez toujours la page de la version exacte avant de choisir une image.

Télécharger et vérifier

  1. Ouvrez la page des versions Gamma Linux.
  2. Choisissez une version publiée et vérifiez que son ISO correspond à votre architecture.
  3. Lisez les notes de version : problèmes connus, identifiants éventuels et consignes propres à l’installateur.
  4. Si une somme SHA-256 est publiée, calculez celle du fichier téléchargé :
sha256sum Gamma-Linux.iso

Comparez le résultat caractère par caractère avec la somme publiée pour cette ISO précise. Toutes les versions ne fournissent pas nécessairement un fichier de sommes.

Téléchargez l’image depuis la page officielle des versions ou depuis une source explicitement indiquée par le projet.

Guide d’installation

Sauvegardez vos données avant toute opération. Le partitionnement et le formatage peuvent effacer définitivement des fichiers. Vérifiez le disque cible avant de confirmer une modification.

1. Préparer la clé USB

Écrivez l’ISO sur une clé USB avec un outil adapté comme Rufus ou Ventoy. Cette opération efface généralement le contenu existant de la clé. Sauvegardez les fichiers qui s’y trouvent.

2. Vérifier le mode BIOS ou UEFI

Ouvrez le menu de démarrage du firmware et choisissez l’entrée USB correspondant au mode de démarrage de la machine. Les touches courantes sont F12, F11, Esc, F8 ou F9, selon le fabricant.

3. Si Windows est installé sur le même ordinateur

Pour une configuration en double démarrage, désactivez le démarrage rapide et l’hibernation depuis une invite de commandes Windows ouverte en administrateur :

powercfg /h off

Effectuez ensuite un arrêt complet de Windows avant de démarrer la clé Gamma. Cette commande désactive aussi l’hibernation. N’accédez pas depuis Linux à une partition Windows en hibernation.

4. Tester la session Live

Démarrez Gamma en mode Live avant l’installation. Vérifiez l’écran, le clavier, le pavé tactile, le stockage, le réseau et la stabilité générale. Si un périphérique essentiel ne fonctionne pas, consultez les notes de version et signalez le problème avant de modifier les partitions.

5. Lancer l’installateur

Si le bureau Live propose le raccourci Install Gamma Linux, ouvrez-le pour lancer Calamares. Vérifiez attentivement la langue, le clavier, le partitionnement, le compte utilisateur et le chargeur d’amorçage. Relisez le résumé final avant de confirmer.

6. Terminer

Lorsque l’installation est terminée, redémarrez et retirez la clé USB lorsque le système le demande. Si le système installé ne démarre pas, notez le message exact et le mode firmware au lieu de modifier les partitions au hasard.

Compiler Gamma Linux depuis les sources

Les scripts de construction et la configuration sont disponibles dans le dépôt source. Le README et les scripts de la branche choisie définissent le processus réel.

Le processus documenté est divisé en étapes :

  1. scripts/01-prepare.sh — préparer le chroot de base.
  2. scripts/02-install-packages.sh — installer les paquets de l’édition.
  3. scripts/03-install-gamma.sh — installer les composants propres à Gamma.
  4. scripts/04-configure.sh — configurer le système.
  5. scripts/05-build-squashfs.sh — créer le système de fichiers Live compressé.
  6. scripts/06-build-efi.sh — préparer les fichiers EFI.
  7. scripts/07-build-iso.sh — créer l’image ISO.
  8. scripts/08-test.sh — lancer les vérifications et les tests QEMU disponibles.

Pour la cible documentée legacy, exécutez :

sudo bash scripts/01-prepare.sh legacy
sudo bash scripts/02-install-packages.sh legacy
sudo bash scripts/03-install-gamma.sh legacy
sudo bash scripts/04-configure.sh legacy
sudo bash scripts/05-build-squashfs.sh legacy
sudo bash scripts/06-build-efi.sh legacy
sudo bash scripts/07-build-iso.sh legacy
bash scripts/08-test.sh legacy

Remplacez legacy par lite ou pro uniquement si ces cibles existent dans la branche utilisée. Installez d’abord les dépendances hôtes indiquées dans le README de cette branche.

Étape destructive : le script documenté 01-prepare.sh supprime les répertoires chroot/, iso/ et output/ du dépôt avant de préparer une nouvelle compilation. Sauvegardez leur contenu important et inspectez le script actuel avant de l’exécuter, surtout sur une autre branche.

Les tests automatisés sont utiles, mais ne remplacent pas les essais de l’ISO Live et de l’installateur sur du matériel réel.

Dépannage

La clé USB n’apparaît pas dans le menu de démarrage

  • Essayez un autre port USB, directement sur la machine.
  • Recréez la clé et vérifiez la somme ISO lorsqu’elle est publiée.
  • Vérifiez le mode Legacy BIOS ou UEFI et choisissez l’entrée correspondante.

L’écran reste noir au démarrage

  • Attendez un peu afin d’écarter un démarrage simplement lent.
  • Consultez les notes de version pour les problèmes graphiques et les options de secours prises en charge.
  • Notez le modèle du GPU et les messages visibles. N’ajoutez pas de paramètres noyau au hasard.

L’installateur ne détecte pas le disque

  • Arrêtez-vous avant de formater ou de modifier la table de partitions.
  • Vérifiez que le firmware détecte le disque et que Windows est complètement arrêté, le cas échéant.
  • Notez le modèle du stockage, le mode du contrôleur et le message de l’installateur.

Réseau, Wi-Fi ou audio absent

Certains appareils nécessitent un firmware ou une prise en charge spécifique. Notez le modèle exact et consultez les notes de version. Évitez les firmwares provenant de sites non fiables.

Le système installé diffère de la session Live

Indiquez l’édition, la version, le mode de démarrage et les étapes pour reproduire le problème. Retirez les mots de passe, clés privées, numéros de série et données personnelles des journaux avant de les partager.

Signaler un problème

Un bon rapport permet de reproduire le problème. Ajoutez :

  • fabricant et modèle du PC ;
  • modèle et architecture du CPU, quantité de RAM et type de stockage ;
  • édition Gamma et version/build exacts ;
  • mode BIOS ou UEFI ;
  • étapes pour reproduire le problème et résultat attendu ;
  • journaux utiles ou capture d’écran lisible, après retrait des informations personnelles.

Envoyez le rapport via GitHub Issues ou par e-mail à founder@mail.gamma-linux.is-local.org.

Foire aux questions

Gamma Linux est-elle gratuite ?

Oui. Gamma Linux est un projet libre et open source. Consultez le fichier de licence du dépôt pour connaître les conditions applicables.

Toutes les éditions prennent-elles en charge le 32 bits ?

Non. La cible Legacy-32 est destinée au matériel x86 32 bits. Lite-Ghost et Pro-MaxMini sont indiquées comme cibles amd64 dans la documentation actuelle du projet.

Les valeurs de RAM sont-elles des minimums garantis ?

Non. Ce sont des objectifs pratiques publiés par le projet. L’utilisation réelle dépend de la version, du matériel, des pilotes et de la charge de travail.

Puis-je installer Gamma à côté de Windows ?

Le double démarrage peut être possible, mais le partitionnement demande de la prudence. Sauvegardez vos données, désactivez le démarrage rapide et l’hibernation, puis vérifiez chaque modification de l’installateur.

Où trouver la dernière ISO ?

Utilisez la page GitHub Releases. Toutes les cibles de compilation ne disposent pas nécessairement d’une ISO publiée.
