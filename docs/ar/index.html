مرحبًا بك في Gamma Linux

Gamma Linux مشروع توزيعة حرة ومفتوحة المصدر، هدفه إعطاء الحواسيب القديمة فرصة جديدة للاستعمال.

اقرأ هذا أولًا: المشروع قيد التطوير المستمر. قد تختلف بيئة سطح المكتب والحزم والمثبّت ودعم العتاد والمتطلبات بين صور ISO. ملاحظات الإصدار المرفقة بالصورة التي تستعملها هي المرجع النهائي.

يشرح هذا التوثيق الخطوات العامة. إذا اختلفت معلومة هنا عن ملاحظات الإصدار أو السكريبتات الموجودة في الفرع الذي تستعمله، فاتبع وثائق ذلك الإصدار.

اختيار الإصدار المناسب

تحقق أولًا من معمارية المعالج، ثم راعِ الذاكرة ومساحة التخزين. الأرقام التالية أهداف عملية منشورة في موقع المشروع، وليست ضمانًا للأداء على كل جهاز.

Legacy-32x86 ‏32-bit (i386)512 MB+8 GB+الحواسيب القديمة ذات 32 بت
Lite-Ghostx86 ‏64-bit (amd64)1 GB+10 GB+أجهزة 64 بت محدودة الموارد
Pro-MaxMinix86 ‏64-bit (amd64)2 GB+15 GB+الأجهزة ذات الموارد الأكبر
تنبيه التوافق: معالج 32 بت لا يستطيع تشغيل صورة amd64. وقد يدعم معالج 64 بت أكثر من وضع، لكن يجب أيضًا أن يتوافق نمط إقلاع البرنامج الثابت وملفات الإقلاع مع الصورة. تحقق من المعالج والـ Firmware قبل التنزيل.

أسماء الإصدارات ومواصفاتها قابلة للتغيير. راجع صفحة الإصدار الذي ستنزّله بالتحديد.

التنزيل والتحقق

  1. افتح صفحة إصدارات Gamma Linux.
  2. اختر إصدارًا منشورًا وتأكد من أن صورة ISO توافق معمارية جهازك.
  3. اقرأ ملاحظات الإصدار لمعرفة المشاكل المعروفة وتعليمات المثبّت وأي معلومات خاصة بتلك النسخة.
  4. إذا نشر المشروع قيمة SHA-256، احسب بصمة الملف الذي نزّلته:
sha256sum Gamma-Linux.iso

قارن النتيجة حرفًا بحرف مع البصمة المنشورة لنفس ملف ISO. لا تفترض أن كل إصدار يحتوي على ملف بصمات.

نزّل الصورة من صفحة الإصدارات الرسمية أو من مصدر يربطه المشروع صراحةً.

دليل التثبيت

أنشئ نسخة احتياطية أولًا. تقسيم الأقراص وتهيئتها قد يؤدي إلى حذف البيانات نهائيًا. احتفظ بنسخة مستقلة من ملفاتك وتأكد من القرص المستهدف قبل تطبيق أي تغيير.

1. تجهيز USB

اكتب صورة ISO إلى ذاكرة USB باستعمال أداة مناسبة مثل Rufus أو Ventoy. هذه العملية تمحو عادة محتوى الذاكرة أو تستبدله، لذلك انسخ ملفاتك منها قبل البدء.

2. التحقق من BIOS أو UEFI

افتح قائمة الإقلاع في Firmware واختر مدخل USB الموافق لوضع الإقلاع في الجهاز. من المفاتيح الشائعة F12 وF11 وEsc وF8 وF9، ويختلف المفتاح حسب الشركة المصنّعة.

3. إذا كان Windows مثبتًا على نفس الجهاز

عند إعداد الإقلاع المزدوج، عطّل Fast Startup والإسبات من موجه أوامر Windows المفتوح بصلاحيات المسؤول:

powercfg /h off

أطفئ Windows إطفاءً كاملًا قبل الإقلاع من USB الخاص بـ Gamma. هذا الأمر يعطّل الإسبات أيضًا. لا تصل من Linux إلى قسم Windows وهو في حالة الإسبات.

4. اختبر الوضع الحي Live

شغّل Gamma في الوضع الحي قبل التثبيت. اختبر الشاشة ولوحة المفاتيح ولوحة اللمس والتخزين والشبكة والاستقرار العام. إذا كان جهاز أساسي لا يعمل، راجع ملاحظات الإصدار وأبلغ عن المشكلة قبل تغيير الأقسام.

5. تشغيل المثبّت

إذا ظهر اختصار Install Gamma Linux في سطح المكتب الحي، افتحه لتشغيل Calamares. راجع اللغة ولوحة المفاتيح وتقسيم الأقراص والمستخدم ومحمّل الإقلاع بعناية. اقرأ الملخص النهائي قبل التأكيد.

6. إنهاء التثبيت

بعد ظهور اكتمال التثبيت، أعد التشغيل وانزع USB عندما يطلب منك ذلك. إذا لم يقلع النظام المثبّت، دوّن رسالة الخطأ ووضع Firmware بدل تغيير الأقسام عشوائيًا.

بناء Gamma Linux من المصدر

سكريبتات البناء وإعدادات المشروع موجودة في مستودع المصدر. ملف README والسكريبتات في الفرع الذي تختاره هي المرجع الفعلي لعملية البناء.

مسار البناء الموثق مقسّم إلى مراحل مرقّمة:

  1. scripts/01-prepare.sh — تجهيز chroot الأساسي.
  2. scripts/02-install-packages.sh — تثبيت حزم الإصدار.
  3. scripts/03-install-gamma.sh — تثبيت مكوّنات Gamma الخاصة.
  4. scripts/04-configure.sh — إعداد النظام.
  5. scripts/05-build-squashfs.sh — إنشاء نظام الملفات الحي المضغوط.
  6. scripts/06-build-efi.sh — تجهيز ملفات EFI.
  7. scripts/07-build-iso.sh — إنشاء صورة ISO.
  8. scripts/08-test.sh — إجراء الفحوصات واختبارات QEMU المتاحة.

بالنسبة إلى الهدف الموثق legacy، تسلسل الأوامر هو:

sudo bash scripts/01-prepare.sh legacy
sudo bash scripts/02-install-packages.sh legacy
sudo bash scripts/03-install-gamma.sh legacy
sudo bash scripts/04-configure.sh legacy
sudo bash scripts/05-build-squashfs.sh legacy
sudo bash scripts/06-build-efi.sh legacy
sudo bash scripts/07-build-iso.sh legacy
bash scripts/08-test.sh legacy

استبدل legacy بـ lite أو pro فقط إذا كان الهدف موجودًا في الفرع الذي تبني منه. ثبّت اعتماديات نظام البناء المذكورة في README الخاص بذلك الفرع أولًا.

خطوة مدمّرة للبيانات: السكريبت الموثق 01-prepare.sh يحذف مجلدات chroot/ وiso/ وoutput/ من المستودع قبل تجهيز بناء جديد. انسخ أي بيانات مهمة منها وافحص السكريبت الحالي قبل تشغيله، خصوصًا عند استعمال فرع آخر.

الفحوصات الآلية مفيدة، لكنها لا تعوّض اختبار ISO الحي والمثبّت على أجهزة حقيقية.

حل المشاكل

USB لا يظهر في قائمة الإقلاع

  • جرّب منفذ USB آخر، ويفضّل منفذًا مباشرًا دون موزّع.
  • أعد كتابة الصورة وتحقق من بصمة ISO إذا كانت منشورة.
  • تحقق هل الجهاز يعمل بوضع Legacy BIOS أو UEFI واختر مدخل الإقلاع الموافق.

الجهاز يقلع لكن الشاشة سوداء

  • انتظر قليلًا للتأكد أن الإقلاع ليس بطيئًا فقط.
  • راجع ملاحظات الإصدار بحثًا عن مشاكل الرسوميات أو خيارات الإقلاع الاحتياطية المدعومة.
  • دوّن طراز بطاقة الرسوميات ورسائل الإقلاع الظاهرة. لا تضف معاملات Kernel عشوائيًا دون فهم تأثيرها.

المثبّت لا يرى القرص أو الأقسام

  • توقف قبل التهيئة أو تعديل جدول الأقسام.
  • تأكد أن Firmware يتعرف على القرص وأن Windows مطفأ بالكامل إن كان مثبتًا.
  • دوّن طراز وحدة التخزين ووضع المتحكم ورسالة المثبّت.

الشبكة أو Wi-Fi أو الصوت لا يعمل

بعض الأجهزة تحتاج Firmware أو دعمًا خاصًا. دوّن طراز القطعة بدقة وراجع ملاحظات الإصدار. تجنب تنزيل Firmware من مواقع غير موثوقة.

النظام المثبّت يختلف عن الوضع الحي

أرسل اسم الإصدار ورقم النسخة ووضع الإقلاع والخطوات التي تعيد المشكلة. احذف كلمات المرور والمفاتيح الخاصة والأرقام التسلسلية والبيانات الشخصية من السجلات قبل مشاركتها.

الإبلاغ عن خلل

التقرير الجيد يساعد على إعادة إنتاج المشكلة. أرفق المعلومات التالية:

  • الشركة المصنّعة للحاسوب والطراز؛
  • طراز المعالج ومعماريته وحجم RAM ونوع التخزين؛
  • إصدار Gamma والنسخة أو البناء بالتحديد؛
  • وضع BIOS أو UEFI؛
  • خطوات إعادة المشكلة والنتيجة التي كنت تتوقعها؛
  • السجلات المهمة أو لقطة شاشة واضحة بعد إزالة المعلومات الشخصية.

أرسل البلاغ عبر GitHub Issues أو عبر البريد founder@mail.gamma-linux.is-local.org.

الأسئلة الشائعة

هل Gamma Linux مجانية؟

نعم. Gamma Linux مشروع مجاني ومفتوح المصدر. راجع ملف الترخيص في المستودع لمعرفة شروط الترخيص.

هل كل الإصدارات تدعم 32 بت؟

لا. إصدار Legacy-32 موجّه إلى عتاد x86 ذي 32 بت. أما Lite-Ghost وPro-MaxMini فهما مدرجان كهدفين amd64 في توثيق المشروع الحالي.

هل أرقام RAM حدود دنيا مضمونة؟

لا. هي أهداف عملية يعرضها المشروع. قابلية الاستخدام الفعلية تتعلق بالإصدار والعتاد والتعريفات وطبيعة العمل.

هل أستطيع تثبيت Gamma بجانب Windows؟

قد يكون الإقلاع المزدوج ممكنًا، لكنه يتطلب تقسيمًا دقيقًا. أنشئ نسخة احتياطية وعطّل Fast Startup والإسبات وراجع كل تغيير يقترحه المثبّت.

أين أجد أحدث ISO؟

استعمل صفحة GitHub Releases. ليس مضمونًا أن يكون لكل هدف بناء ملف ISO منشور للتنزيل.

لم يتم العثور على قسم مطابق.
